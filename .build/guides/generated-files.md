Do **not** hand-edit these. Regenerate them, or leave them alone:

- **Built portal assets:** `healthcare/public/frontend/assets/*` (hashed `patient_portal-*.js/.css/.map`, committed) and `healthcare/public/patient_portal/assets` (the Vite `outDir`). Rebuild with `yarn build`. `healthcare/www/patient_portal.html` is also written by the frappe-ui Vite plugin (`indexHtmlPath`).
- **`healthcare/public/dist/`**, `dist/`, `node_modules/` (including `healthcare/public/node_modules`): build output and dependencies, excluded from pre-commit or gitignored.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: auto-generated type stubs (`/* eslint-disable */ /* prettier-ignore */`).
- **`healthcare/locale/main.pot`**: regenerated by `.github/helper/update_pot_file.sh` (weekly workflow). `*.po` translations come from Crowdin.
- **Lockfiles:** `yarn.lock`. Change it only through yarn.
- **`.secrets.baseline`**: managed by `detect-secrets`.
- **`healthcare/docs/current`**, `*.egg-info`, `__pycache__/`, `.ruff_cache/`: gitignored or generated.
- **`healthcare/__init__.py` version string**: rewritten by semantic-release (`.releaserc` prepareCmd).
- **DocType `*.json`** files are exported by Frappe when you save in the DocType editor. Edits are allowed, but keep `fields`/`field_order` consistent.
- `.goals/`, `.tasks/`: local Build engine state (untracked).
