Do not edit these by hand:

- **`healthcare/public/frontend/assets/*`** holds the built patient-portal bundles (hashed `patient_portal-<hash>.js/.css/.map`). They are committed but generated by `yarn build`, and pre-commit skips them. Change `patient_portal/src` and rebuild. Note that `vite.config.js` sets `outDir` to `healthcare/public/patient_portal/assets`, while the committed bundles sit in `public/frontend/assets`. Check which path a change actually touches.
- **`healthcare/www/patient_portal.html`** is written by the frappe-ui Vite plugin (`indexHtmlPath`).
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`** are type stubs generated by the build plugins.
- **`healthcare/locale/main.pot`** is regenerated weekly by `generate-pot-file.yml` / `.github/helper/update_pot_file.sh`. The `*.po` translations come from Crowdin (`crowdin.yml`).
- **`healthcare/__init__.py` version string** is bumped by semantic-release (`.releaserc` prepareCmd). Do not change it by hand.
- **Lockfiles:** `yarn.lock`. Ignored build artefacts: `dist/`, `node_modules/` (including `healthcare/public/node_modules`), `*.egg-info`, `__pycache__/`, `healthcare/docs/current`.
- **DocType `*.json`** files are exported by Frappe from the DocType editor. Edit them through Desk or keep them consistent with the export format. During upstream syncs, merge `fields`/`field_order` as a 3-way union.
- `.secrets.baseline` is maintained by detect-secrets.
