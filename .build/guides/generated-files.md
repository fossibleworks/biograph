# Generated and vendored files

Do not hand-edit these files.

- **Built portal assets:** `healthcare/public/frontend/assets/patient_portal-*.js(.map)/.css`, `healthcare/public/frontend/index.html` and `manifest.json`. These are Vite output and are committed. The current `vite.config.js` writes to `healthcare/public/patient_portal/assets` and to `healthcare/www/patient_portal.html`, so regenerate with `yarn build` rather than editing them.
- **`patient_portal/auto-imports.d.ts` and `components.d.ts`:** generated by the frappe-ui/unplugin auto-import plugins.
- **`healthcare/locale/main.pot`:** regenerated weekly by `generate-pot-file.yml`. `.po` files come from Crowdin PRs ("fix: sync translations from crowdin").
- **Lockfiles:** `yarn.lock`. Change it only through yarn.
- **Version string in `healthcare/__init__.py`:** semantic-release rewrites it on release branches. The fork bumps it with a `chore: bump version` commit.
- **`.secrets.baseline`:** managed by `detect-secrets`.
- **Ignored output** (per `.gitignore`): `dist/`, `node_modules/`, `__pycache__/`, `*.egg-info`, `healthcare/docs/current`. Pre-commit also excludes `healthcare/public/dist/` and `healthcare/public/frontend/assets/`.
- **Doctype `.json` files** are normally written by the Frappe DocType editor. Manual edits are fine but must keep valid JSON and the `fields`/`field_order` consistency.
- **`healthcare/public/node_modules`** is a committed symlink to one developer's bench path. Treat it as an accident: do not depend on it, and do not add more.
