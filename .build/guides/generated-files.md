# Generated / vendored files

Do not hand-edit these:

- **Portal build output:** `healthcare/public/frontend/` is committed (hashed `assets/patient_portal-*.js/.css`, `index.html`). Vite emits into `healthcare/public/patient_portal/assets` and rewrites `healthcare/www/patient_portal.html` (`indexHtmlPath`). Regenerate with `yarn build`; never edit the output.
- **Vue codegen:** `patient_portal/components.d.ts` and `patient_portal/auto-imports.d.ts`, generated by unplugin-vue-components/auto-import.
- **Lockfile:** `yarn.lock`. Change it only through yarn.
- **Translations:** `healthcare/locale/main.pot` is regenerated weekly by `generate-pot-file.yml` / `.github/helper/update_pot_file.sh`.
- **Version string:** semantic-release rewrites `healthcare/__init__.py` `__version__` (via `.releaserc`).
- **Secrets baseline:** `.secrets.baseline` belongs to detect-secrets. Update it with the tool.
- **Build-managed:** `.github/instructions/build-rules.instructions.md`, `.claude/rules/build-rules.md`, and the `BEGIN/END BUILD GUIDES` block in `AGENTS.md` are generated from `.build/RULES.md`. Edit the source instead.
- **Ignored:** `dist/`, `node_modules/`, `__pycache__/`, `*.egg-info`, `healthcare/docs/current`.
- **Doctype JSON** (`<doctype>.json`) is normally edited through the Frappe desk DocType editor, then exported. When merging, keep `fields` and `field_order` consistent.
