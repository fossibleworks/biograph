Do not hand-edit these paths.

- **`healthcare/public/frontend/assets/*`**: compiled Patient Portal bundles with hashed names (`patient_portal-<hash>.js/.css/.map`). They are committed. Regenerate them with `yarn build` and never edit them by hand. Note that `patient_portal/vite.config.js` sets `outDir` to `healthcare/public/patient_portal/assets`, so check where a build actually writes before you commit.
- **`healthcare/public/dist/`, `dist/`, `node_modules/`, `healthcare/public/node_modules`**: build output and dependencies. They are gitignored or excluded from linters.
- **`healthcare/locale/main.pot`**: regenerated weekly by the `generate-pot-file.yml` workflow (`.github/helper/update_pot_file.sh`). `.po` translations arrive from Crowdin as `fix: <lang> translations` PRs.
- **`healthcare/__init__.py` version string**: written by semantic-release (`@semantic-release/exec` sed + `@semantic-release/git`). Do not bump it manually.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by the frappe-ui/Vite auto-import plugins.
- **Lockfiles**: `yarn.lock`. Update it only through yarn.
- **`.github/instructions/build-rules.instructions.md`, the Build Guides block in `AGENTS.md`, `.claude/rules/build-rules.md`**: generated by Interactor Build from `.build/RULES.md`. Edit the source file instead.
- **`.secrets.baseline`**: the detect-secrets baseline. Update it with `detect-secrets scan --baseline .secrets.baseline`.
- **`healthcare/docs/current`**: gitignored.
- Doctype `*.json` files are produced by the Frappe desk DocType editor. Hand edits are allowed, but keep the `field_order`/`fields` structure consistent.
