Do not hand-edit these paths. Regenerate them instead.

- **Portal build output:** `healthcare/public/patient_portal/assets/`, `healthcare/public/frontend/assets/`, and `healthcare/www/patient_portal.html` (Vite writes this index HTML). Regenerate with `yarn build`.
- **`healthcare/public/dist/`, `dist/`, `node_modules/`, `*.egg-info`, `__pycache__/`:** build artifacts, gitignored or excluded from pre-commit.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`:** generated by the frappe-ui/unplugin Vite plugins.
- **Lockfiles:** `yarn.lock`. Change it only through yarn.
- **Translations:** `healthcare/locale/main.pot` is regenerated weekly by `generate-pot-file.yml`. The `.po` files are synced from Crowdin (`crowdin.yml`). Do not edit the `.po` files by hand.
- **Version:** semantic-release rewrites the version string in `healthcare/__init__.py` on release branches.
- **DocType JSON** (`doctype/<name>/<name>.json`) is normally written by the Frappe desk DocType editor. Hand edits must keep `fields` and `field_order` consistent.
- **`.secrets.baseline`** is maintained by detect-secrets.
