Do not hand-edit these paths:

- **SPA build output:** `healthcare/public/patient_portal/assets/` (Vite `outDir`), `healthcare/public/frontend/assets/` and `healthcare/public/dist/`. Regenerate them with `yarn build`. They are excluded from pre-commit and Prettier.
- **`healthcare/www/patient_portal.html`**: written by the frappe-ui Vite plugin (`indexHtmlPath`).
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by the frappe-ui/unplugin tooling.
- **`healthcare/locale/main.pot`**: translation template, regenerated weekly by the `generate-pot-file.yml` workflow (`.github/helper/update_pot_file.sh`).
- **Lockfiles:** `yarn.lock`. Change it only through yarn.
- **Doctype JSON** (`doctype/*/*.json`, workspace, report, number-card JSON): exported by Frappe from Desk. Edit through Desk and export, or edit carefully by hand. Keep `fields` and `field_order` consistent.
- **Version string in `healthcare/__init__.py`**: rewritten by semantic-release (`.releaserc` prepareCmd).
- **Build-managed mirrors:** `AGENTS.md` (the BUILD GUIDES block), `.claude/rules/build-rules.md`, `.cursor/rules/build-rules.mdc`, `.github/instructions/build-rules.instructions.md`. These are generated from `.build/RULES.md`, so edit the source instead.
- **Ignored:** `node_modules/`, `dist/`, `__pycache__/`, `*.pyc`, `*.egg-info`, `healthcare/docs/current`, `.ruff_cache`.
- **`.secrets.baseline`**: maintained by detect-secrets.
