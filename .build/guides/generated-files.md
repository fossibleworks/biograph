Do not hand-edit these. Regenerate them with the owning tool:

- **`healthcare/public/frontend/assets/*`**: committed Vite build output of the Patient Portal (hashed `patient_portal-<hash>.js/.css/.map`). Regenerate with `yarn build`. Never edit by hand.
- **`healthcare/www/patient_portal.html`**: SPA index emitted by the frappe-ui Vite plugin (`indexHtmlPath`).
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by the frappe-ui/unplugin auto-import tooling.
- **`healthcare/locale/main.pot`**: regenerated weekly by the `generate-pot-file` workflow. Translations (`*.po`) arrive through Crowdin PRs (`fix: sync translations from crowdin`).
- **`yarn.lock`**: lockfile. Change it only through yarn.
- **`.secrets.baseline`**: detect-secrets baseline. Update it with `detect-secrets scan --baseline .secrets.baseline`.
- **Version string in `healthcare/__init__.py`**: bumped by semantic-release on the stable `version-*` branches.
- **DocType `*.json`**: Frappe schema files, normally produced by the DocType editor in developer mode. Hand edits must stay valid Frappe JSON. During upstream syncs, merge `fields`/`field_order` as a 3-way union.
- **Ignored:** `__pycache__/`, `*.pyc`, `*.egg-info`, `dist/`, `node_modules/`, `healthcare/docs/current`, `.ruff_cache`.
