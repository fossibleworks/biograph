Never hand-edit these. Regenerate them instead.

- **Patient Portal build output.** `vite build` writes these from `patient_portal/src`:
  - `healthcare/public/frontend/assets/*` (hashed `patient_portal-*.js/.css/.map`, which are committed)
  - `healthcare/public/patient_portal/assets`
  - `healthcare/www/patient_portal.html` (via `indexHtmlPath`)
  - `healthcare/public/dist/` (Frappe bundle output)
- **Translations:**
  - `healthcare/locale/main.pot` is regenerated weekly by the `generate-pot-file.yml` workflow.
  - `healthcare/locale/*.po` files are synced from Crowdin.
- **Release version:** semantic-release rewrites the version string in `healthcare/__init__.py` on version-* branches.
- **Lockfiles:** `yarn.lock`. Update it only through yarn.
- **Doctype JSON** (`doctype/*/*.json`): produced by Frappe's DocType editor and exported in Developer Mode. Edits must preserve the `fields`/`field_order` structure and the `modified` timestamp semantics.
- **Type stubs:** `patient_portal/components.d.ts` and `auto-imports.d.ts` are auto-generated by Vite plugins.
- **Ignored, never commit:** `node_modules/`, `dist/`, `__pycache__/`, `*.pyc`, `*.egg-info`, `healthcare/docs/current`, `.ruff_cache`, `.env`.
- **Secrets baseline:** `.secrets.baseline` is maintained by `detect-secrets`.
- `.git-blame-ignore-revs` lists bulk-format commits.
