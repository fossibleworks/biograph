- `healthcare/public/frontend/assets/*` (hashed `patient_portal-*.js/.css/.map`) and `healthcare/www/patient_portal.html`: Vite build output from `patient_portal/`. These files are committed. Rebuild with `yarn build`.

- `healthcare/__init__.py` `__version__`: bumped by semantic-release on the `version-*` branches. On the fork, keep the fork's version.
- `patient_portal/auto-imports.d.ts` and `patient_portal/components.d.ts`: generated by frappe-ui/unplugin.
- `.secrets.baseline`: detect-secrets baseline. Update it with `detect-secrets scan --baseline`.
- `.github/instructions/build-rules.instructions.md`, `.claude/rules/build-rules.md` and the guides block in `AGENTS.md`: generated by Interactor Build from `.build/RULES.md`. Edit the source file instead.
