# Generated & vendored files

Do not hand-edit these. Regenerate them instead.

- **`healthcare/public/frontend/`** (e.g. `assets/patient_portal-<hash>.js/.css/.map`, `index.html`): committed Vite build output of the patient portal. Edit `patient_portal/src` and rebuild. Note that `patient_portal/vite.config.js` points `outDir` at `healthcare/public/patient_portal/assets`, so check which path is actually served before rebuilding.
- **`healthcare/public/dist/`, `dist/`, `node_modules/`, `*.egg-info`, `__pycache__/`**: build artefacts. They are git-ignored and excluded from pre-commit.
- **`healthcare/locale/main.pot`**: regenerated weekly by the `generate-pot-file.yml` workflow. Crowdin opens PRs for the `*.po` translation files.
- **`healthcare/docs/current`**: ignored.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by the frappe-ui/Vite plugins.
- **`yarn.lock`**: change it only through yarn.
- **`.secrets.baseline`**: the detect-secrets baseline. Update it with `detect-secrets scan --baseline`.
- **The version string in `healthcare/__init__.py`**: semantic-release (`.releaserc`) rewrites it on release branches.
- **Doctype `*.json`**: Frappe writes these when you save in the DocType editor. Hand edits are acceptable, but keep `fields` and `field_order` consistent.
- **`.goals/`, `.tasks/`, `.env`**: local Build/engine state. Never commit them.
