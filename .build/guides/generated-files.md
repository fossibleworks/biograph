Do not hand-edit these files:

- **`healthcare/public/frontend/assets/*`** holds the built Patient Portal bundles (hashed `patient_portal-*.js/.css/.map`). They come from `patient_portal/`. To change them, edit the source and run `yarn build`. Pre-commit excludes this path.
- **`healthcare/public/dist/`** and any `dist/` are build output (gitignored or excluded from lint).
- **`node_modules/`**, including `healthcare/public/node_modules`, is gitignored dependency output.
- **`healthcare/locale/main.pot`** is regenerated weekly by `generate-pot-file.yml` (`.github/helper/update_pot_file.sh`). `.po` translations arrive through Crowdin PRs.
- **`yarn.lock`** is a lockfile. Change it only through yarn.
- **`healthcare/__init__.py` `__version__`** is bumped by semantic-release (`.releaserc` prepareCmd).
- **`patient_portal/auto-imports.d.ts` and `components.d.ts`** are generated by the frappe-ui/Vite plugins.
- **Doctype `*.json` files** are written by Frappe's DocType editor (developer mode). They are edited by hand during upstream syncs, using a 3-way union of `fields` and `field_order`.
- **`.secrets.baseline`** is maintained by detect-secrets.
- **`.ruff_cache/`, `__pycache__/`** are tool caches.
- **`.goals/`, `.tasks/`, `.env`** are local, untracked engine and workspace state. Never commit them.
- The generated **AGENTS.md** block and **`.github/instructions/build-rules.instructions.md`** are rendered from `.build/RULES.md` and `.build/guides/`. Edit the source instead.
