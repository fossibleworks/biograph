Do not edit these paths by hand.

- **Built portal bundles** go to `healthcare/public/frontend/assets/*` (hashed `patient_portal-<hash>.js/.css/.js.map`, committed to git) and `healthcare/public/patient_portal/assets` (the Vite `outDir`). The portal HTML entry `healthcare/www/patient_portal.html` is also written by the frappe-ui Vite plugin (`indexHtmlPath`). To change any of these, edit `patient_portal/src` and rebuild.
- `healthcare/public/dist/` is Frappe build output and is excluded from pre-commit.
- `patient_portal/auto-imports.d.ts` and `patient_portal/components.d.ts` are type stubs generated by the frappe-ui and Vite plugins.
- `healthcare/locale/main.pot` is regenerated every week by the `generate-pot-file.yml` workflow (`.github/helper/update_pot_file.sh`). The `*.po` files come from Crowdin.
- **Lockfiles:** `yarn.lock`. Only change it through yarn.
- Gitignored: `dist/`, `node_modules/`, `__pycache__/`, `*.pyc`, `*.egg-info`, `healthcare/docs/current`.
- `healthcare/__init__.py` holds the version string, which semantic-release rewrites. Do not bump it by hand.
- Build-managed mirrors are generated from `.build/RULES.md`: `AGENTS.md` (the BUILD GUIDES block), `.claude/rules/build-rules.md`, `.cursor/rules/build-rules.mdc` and `.github/instructions/build-rules.instructions.md`. Edit the source file instead.
- `.secrets.baseline` is maintained by detect-secrets.
