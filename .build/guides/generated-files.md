Do not hand-edit these. Regenerate them with the owning tool.

- **Patient portal build output:** `healthcare/public/frontend/**` (hashed `patient_portal-*.js/.css/.map`, `index.html`, `manifest.json`), the `healthcare/public/patient_portal/assets` output dir, and `healthcare/www/patient_portal.html` (the frappe-ui vite `indexHtmlPath`). Rebuild them with `yarn build`.
- **frappe-ui codegen:** `patient_portal/components.d.ts` and `patient_portal/auto-imports.d.ts` ("Generated by unplugin-vue-components").
- **Translation template:** `healthcare/locale/main.pot`. The scheduled `generate-pot-file.yml` workflow regenerates it through `.github/helper/update_pot_file.sh`.
- **Version string:** `healthcare/__init__.py` `__version__`. semantic-release rewrites it on stable branches, and the fork bumps it with `chore: bump version to X`.
- **Lockfiles:** `yarn.lock`. Update it only through yarn.
- **Build-managed agent docs:** `.github/instructions/build-rules.instructions.md`, `.claude/rules/build-rules.md`, and the BUILD GUIDES block in `AGENTS.md` are generated from `.build/RULES.md`. Edit the source file instead.
- **DocType JSON:** `doctype/*/*.json` is normally exported by Frappe when you save in the desk. Hand edits are fine but must keep `fields` and `field_order` consistent.
- **Ignored:** `dist/`, `node_modules/` (including `healthcare/public/node_modules`), `__pycache__/`, `*.pyc`, `*.egg-info`, `healthcare/docs/current`, `.ruff_cache`.
- **Secrets baseline:** `.secrets.baseline` is maintained by `detect-secrets`.
