Do not hand-edit these files:
- **`healthcare/public/frontend/`** (`assets/patient_portal-*.js/.css/.map`, `index.html`): the committed Vite build of `patient_portal/`. Change the Vue source and rebuild. Note that `patient_portal/vite.config.js` sets `outDir` to `healthcare/public/patient_portal/assets`, so make sure the build output lands where the app serves it from.
- **`healthcare/public/dist/`** and `dist/`: build output (gitignored or excluded from pre-commit).
- **`node_modules/`**, including `healthcare/public/node_modules`: gitignored.
- **`healthcare/locale/main.pot`**: regenerated by the weekly *Regenerate POT file* workflow.
- **`healthcare/__init__.py` `__version__`**: bumped by semantic-release (`.releaserc` prepareCmd). Do not bump it by hand on release branches.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by the frappe-ui/unplugin tooling.
- **Lockfiles:** `yarn.lock`.
- **`.secrets.baseline`**: detect-secrets baseline. Update it with the tool, never by hand.
- **Build-managed files:** `.github/instructions/build-rules.instructions.md`, `.claude/rules/build-rules.md`, and the `BEGIN/END BUILD GUIDES` block in `AGENTS.md` are generated from `.build/RULES.md`. Edit the source file instead.
- **DocType `*.json`** files are exported by Frappe's DocType editor. Hand edits are allowed but must stay valid exports: keep `fields` and `field_order` consistent.
- `healthcare/docs/current` is gitignored.
