# Generated and vendored files

Do not hand-edit these:

- `healthcare/public/patient_portal/assets/` is the Vite build output of `patient_portal/`. Regenerate it with `yarn build`.
- `healthcare/public/frontend/assets/` and `healthcare/public/dist/` are built frontend bundles. pre-commit excludes them.
- `healthcare/www/patient_portal.html` is the index HTML that the frappe-ui Vite plugin writes (`indexHtmlPath`).
- `patient_portal/auto-imports.d.ts` and `patient_portal/components.d.ts` are auto-generated by the frappe-ui/unplugin tooling.
- `healthcare/locale/main.pot` is regenerated weekly by the `generate-pot-file` workflow. The `.po` translations come from Crowdin PRs.
- `yarn.lock` is the lockfile. Update it only through yarn.
- `healthcare/__init__.py` holds the version string, which semantic-release rewrites on release.
- `.secrets.baseline` is the detect-secrets baseline. Update it only with the tool.
- Ignored paths: `dist/`, `node_modules/`, `*.egg-info`, `__pycache__/`, `healthcare/docs/current`.

DocType `.json` files are edited through the Frappe DocType UI (developer mode) and exported. Keep manual edits minimal and consistent with what Frappe would export.
