Do not hand-edit these:

- `healthcare/public/frontend/` and `healthcare/www/patient_portal.html`: Vite build output from `patient_portal/`. Rebuild them instead of editing.
- `healthcare/public/dist/`, `dist/`, `node_modules/`, `healthcare/public/node_modules`: build output and dependencies (gitignored or excluded from linters).
- `patient_portal/auto-imports.d.ts` and `components.d.ts`: generated by frappe-ui/unplugin.
- `healthcare/locale/main.pot`: regenerated weekly by the `generate-pot-file` workflow. `*.po` translations come from Crowdin.
- `yarn.lock`: lockfile. Change it only through yarn.
- `.secrets.baseline`: maintained by detect-secrets.
- `healthcare/__init__.py` version string: bumped by semantic-release.
- `healthcare/docs/current`: gitignored.
- Managed blocks in `AGENTS.md`, `CLAUDE.md`, `.github/instructions/build-rules.instructions.md`, and `.claude/rules` are generated by Build from `.build/RULES.md`. Edit the source file, not these copies.
- Doctype `*.json` files are written by Frappe's DocType editor. Hand edits must keep valid JSON and the `field_order`.
