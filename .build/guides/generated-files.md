# Generated and vendored files

Do not hand-edit these files. Regenerate them with the tool named for each.

- **`healthcare/public/frontend/assets/*`**: hashed Vite build output of the patient portal, such as `patient_portal-<hash>.js`, `.js.map` and `.css`. These files are committed. Rebuild them with `yarn build`.
- **`healthcare/www/patient_portal.html`**: written by the frappe-ui Vite plugin (`indexHtmlPath`).
- **`healthcare/public/dist/`**: Frappe asset build output. It is excluded from pre-commit.
- **`healthcare/locale/main.pot`**: regenerated every week by the *Regenerate POT file* workflow. The `*.po` translations come from Crowdin PRs titled "fix: sync translations from crowdin".
- **`healthcare/__init__.py` version string**: bumped by semantic-release (`chore(release): Bumped to Version x.y.z`). Do not bump it by hand on release branches.
- **Lockfiles**: `yarn.lock`. Change it only through yarn.
- **`node_modules/`, `healthcare/public/node_modules`, `dist/`, `*.egg-info`, `__pycache__/`, `*.pyc`**: ignored or symlinked dependencies.
- **`.secrets.baseline`**: the detect-secrets baseline. Update it with `detect-secrets scan --baseline`.
- **`patient_portal/auto-imports.d.ts` and `components.d.ts`**: type stubs generated by the frappe-ui/Vite plugin.
- **DocType `*.json`** is normally edited through Frappe's DocType UI or exported by bench, and is treated as data-model source. When editing it by hand, keep `field_order` consistent with `fields`.
