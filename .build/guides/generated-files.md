# Generated / vendored files

Do not hand-edit these files. Regenerate them instead.

- **`healthcare/public/frontend/assets/`, `healthcare/public/patient_portal/assets/`, `healthcare/www/patient_portal.html`**: Vite build output from `patient_portal/` (see `vite.config.js` `outDir` / `indexHtmlPath`). Edit `patient_portal/src` and run `yarn build`.
- **`healthcare/public/dist/`, `dist/`**: build output. These are gitignored or excluded from pre-commit.
- **`node_modules/`** (including `healthcare/public/node_modules`): gitignored.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by frappe-ui/unplugin type helpers.
- **`healthcare/locale/main.pot`**: regenerated weekly by `generate-pot-file.yml` (`.github/helper/update_pot_file.sh`). Crowdin syncs the `.po` translations.
- **`yarn.lock`**: the lockfile. Update it only through yarn.
- **`healthcare/__init__.py` version**: semantic-release bumps it on release branches.
- **`.secrets.baseline`**: maintained by detect-secrets.
- **`.ruff_cache/`, `__pycache__/`, `*.egg-info`**: tool caches.
- **`healthcare/docs/current`**: gitignored.
- **DocType `.json` files** are normally written by the Frappe Desk DocType editor. Keep manual edits minimal, and merge `fields` / `field_order` carefully.
