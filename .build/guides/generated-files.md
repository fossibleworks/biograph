# Generated and vendored files

Do not hand-edit these:

- **`yarn.lock`**: lockfile. Change it only through `yarn install`.
- **`healthcare/public/patient_portal/assets/`** and **`healthcare/www/patient_portal.html`**: Vite build output of `patient_portal/`. Run `yarn build` instead of editing them.
- **`patient_portal/auto-imports.d.ts`** and **`patient_portal/components.d.ts`**: generated by the frappe-ui/Vite plugins.
- **`healthcare/public/dist/`** and **`dist/`**: Frappe asset build output (gitignored).
- **`node_modules/`**, **`__pycache__/`**, **`*.egg-info`**: gitignored. Also `healthcare/docs/current`.
- **`healthcare/locale/main.pot`**: translatable strings. The `generate-pot-file.yml` workflow regenerates it weekly via `.github/helper/update_pot_file.sh`. Crowdin syncs `.po` files back with `fix: <lang> translations` PRs.
- **`healthcare/__init__.py` `__version__`**: semantic-release rewrites it on `version-*` branches (`.releaserc`). The fork keeps its own version during upstream syncs.
- **`.secrets.baseline`**: maintained by `detect-secrets`.

DocType `*.json` files are written by Frappe's DocType editor, but they are checked in and reviewed. During upstream syncs, merge `fields`/`field_order` as a 3-way union.
