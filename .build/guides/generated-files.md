# Generated and vendored files

Do not hand-edit these. Regenerate them with the tool that owns them.

| Path | Source |
|---|---|
| `healthcare/public/patient_portal/assets/`, `healthcare/public/dist/` | Vite build output of `patient_portal/` (`yarn build`). `dist/` is gitignored. |
| `healthcare/www/patient_portal.html` | Written by the frappe-ui Vite plugin (`indexHtmlPath`) during the portal build |
| `healthcare/public/frontend/assets/` | Built frontend assets (excluded from pre-commit) |
| `patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts` | Auto-generated by Vite/unplugin type generation |
| `healthcare/locale/main.pot` | Regenerated weekly by the `generate-pot-file.yml` workflow (`.github/helper/update_pot_file.sh`) |
| `healthcare/locale/*.po` | Pushed by Crowdin (`fix: <lang> translations`) |
| `healthcare/__init__.py` `__version__` | Bumped by semantic-release on version-* branches |
| `yarn.lock` | Yarn lockfile; change it only through `yarn` |
| `.secrets.baseline` | detect-secrets baseline; update with `detect-secrets scan --baseline` |
| `node_modules/`, `healthcare/public/node_modules`, `__pycache__/`, `*.egg-info`, `healthcare/docs/current` | Gitignored / installed artifacts |

DocType `*.json` files are written by the Frappe DocType editor and `bench`, but they are committed source. When merging upstream, union `fields` / `field_order` rather than overwriting.
