Do not hand-edit these. Regenerate them from their source instead.

- **`healthcare/public/frontend/assets/*`** (`patient_portal-<hash>.js/.css/.map`), `healthcare/public/frontend/index.html` and `manifest.json`: committed **build output** of the Vue portal. Edit `patient_portal/src/` and run `yarn build`. pre-commit excludes `healthcare/public/frontend/assets/` and `healthcare/public/dist/`.
- **`healthcare/www/patient_portal.html`**: Vite writes this file as the portal `indexHtmlPath`.
- **`patient_portal/auto-imports.d.ts`, `patient_portal/components.d.ts`**: generated by the frappe-ui/unplugin auto-import tooling.
- **`healthcare/locale/main.pot`**: regenerated weekly by `generate-pot-file.yml` (`.github/helper/update_pot_file.sh`). Crowdin syncs the `.po` translations.
- **`healthcare/__init__.py` `__version__`**: semantic-release bumps it on release branches.
- **Doctype `*.json`**: the Frappe Desk/DocType editor normally exports these. Keep them consistent with the controller `.py` and the type annotations.
- **Lockfiles**: `yarn.lock` (root). Do not hand-edit.
- **Ignored** (`.gitignore`): `node_modules/`, `dist/`, `*.egg-info`, `__pycache__/`, `healthcare/docs/current`. The portal also ignores `dist`, `dist-ssr`, `*.local`.
- **`.secrets.baseline`**: maintained with `detect-secrets` (baseline update), not by hand.
