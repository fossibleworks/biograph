**Python (ruff, `pyproject.toml`):**
- **Tabs** for indentation, double quotes, line length 110 (E501 ignored), target py310.
- Lint selects F, E, W, I, UP, B, RUF, with ignores such as F401, E402, B904, and E741.
- Import sections run future → stdlib → third-party → **frappe** → **erpnext** → **healthcare** → first-party → local.
- `frappe.types.DF` is a typing module (doctype controllers use autogenerated type hints).
- Wrap user-facing strings in `_()` (`from frappe import _`).
- Use `@frappe.whitelist()` for client-callable functions.
- Use `frappe.qb` or `frappe.db.get_value`/`get_all` in preference to raw SQL. Semgrep enforces Frappe rules.

**JavaScript (ESLint flat config + Prettier):**
- Tabs, tabWidth 4, printWidth 88, `arrowParens: avoid`.
- `eslint:recommended`, with Frappe globals (`frappe`, `erpnext`, `$`, `moment`, …) declared.
- Wrap UI strings in `__()`.
- Form scripts use `frappe.ui.form.on('<DocType>', { ... })`.

**Naming:**
- DocType folders and files are snake_case versions of the Title Case DocType name (e.g. `Patient Appointment` → `patient_appointment/patient_appointment.py`).
- Tests are `test_<name>.py`.
- Patches live in `patches/v<major>_0/<verb_phrase>.py`.

**Legacy exclusions:** about 620 existing files are listed in the pre-commit global `exclude`. Do not mass-reformat them. Avoid broad style churn in upstream-synced files (see `.git-blame-ignore-revs`).

**Commits:** Conventional Commits, enforced by commitlint (`feat|fix|chore|docs|refactor|perf|test|ci|build|style|revert`, lower-case type, non-empty subject).
