This is a single Frappe app. The repo root holds the app package `healthcare/` plus the portal frontend source.

```
healthcare/                 # Frappe app package
  hooks.py                  # wiring: doc_events, scheduler_events, override_doctype_class, app_include_js
  healthcare/               # the "Healthcare" module (modules.txt)
    doctype/<snake_name>/   # one dir per DocType: .json schema, .py controller, .js form script, test_*.py
    api/patient_portal.py   # whitelisted endpoints consumed by the Vue portal
    custom_doctype/         # extensions of ERPNext doctypes (HealthcareSalesInvoice, payment_entry hooks)
    utils.py                # shared billing/invoice helpers (large)
    report/, page/, workspace/, dashboard_chart*/, number_card/, print_format/, web_form/
  controllers/              # shared controllers (service_request_controller.py, queries.py)
  regional/india/abdm/      # regional integration
  patches/v0_0|v15_0|v16_0/ + patches.txt   # data migrations ([pre_model_sync]/[post_model_sync])
  public/js/                # desk JS bundled via healthcare.bundle.js
  www/patient_portal.*      # portal route; HTML is generated by the Vite build
  tests/utils.py            # HealthcareTestSuite + bootstrap master data
  locale/main.pot           # translations source
patient_portal/             # Vue 3 + frappe-ui SPA source (src/components, src/utils)
wiki/                       # fork design docs and upstream-sync ledger
```

**How the parts call each other**
- `hooks.py` binds healthcare logic into ERPNext documents. It overrides the `Sales Invoice` class, and its `doc_events` cover Sales Invoice, Payment Entry, Company and Patient, plus a `"*"` wildcard hook that writes patient medical records on submit, cancel and update. `scheduler_events` runs appointment reminders (`all`) and daily status updates for appointments, fee validity, inpatient billables and medication requests.
- Doctype controllers import each other directly by full dotted path (`healthcare.healthcare.doctype.<x>.<x>`). They import ERPNext modules for accounting and stock.
- Desk JS calls Python through `frappe.call` on `@frappe.whitelist()` methods. The portal calls `healthcare.healthcare.api.patient_portal.*` through frappe-ui resources.
- Schema changes live in doctype `.json` files. Data migrations are patch modules registered in `patches.txt`.
- **Fork relationship:** this repo (`biograph-fh` default branch) is periodically synced from upstream `earthians/marley` with `git cherry-pick -x`. When fork and upstream conflict, the fork's intent wins (see `wiki/upstream-sync-version-16.md`).
