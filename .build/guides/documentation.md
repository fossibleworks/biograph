- **User docs** are hosted externally. The README links DeepWiki (`deepwiki.com/Tacten/biograph`). Upstream's `docs_checker` workflow requires `feat` PRs to link a `/wiki` page on biograph.frappe.cloud or biograph.io, unless the PR body says `no-docs` or `backport`.
- **In-repo design and usage docs** go in `wiki/` as standalone Markdown files, usually UPPER-KEBAB-CASE (`DESIGN-BLOCKBASED-THERAPY-APPOINTMENT-BOOKING.md`, `PATIENT-DUPLICATE-CHECKER-USAGE-DOC.md`) with images alongside. Long-running process ledgers also live there (`wiki/upstream-sync-version-16.md`), updated with `docs(wiki): …` commits.
- `patient_portal/README.md` documents the portal.
- **Agent/contributor rules:** `CLAUDE.md` → `.build/RULES.md`, mirrored to `AGENTS.md`, `.claude/rules/`, `.cursor/rules/`, and `.github/instructions/`. The mirrors are generated by Build, so edit the `.build/` source only.
- The PR template asks contributors to update the relevant documentation.
